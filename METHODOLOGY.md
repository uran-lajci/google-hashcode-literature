# Methodology

This document describes how the works in this list were found and selected.

## Scope

The list covers the 21 Google Hash Code problems from 2014 to 2022, across
practice, qualification and final rounds. The searches were carried out
in [month(s) year].

## Search queries

Each problem had its own set of queries. Every query combined the competition
name, in both spellings ("Hash Code" and "HashCode"), with the problem name and
two to four terms describing the problem's content, such as "guaranteed
capacity" for Optimize a Data Center or "interest factor" for Photo Slideshow.
For example:

    "Hash Code" "Photo Slideshow" "interest factor"

Many problem names overlap with established research fields, including data
center optimization, drone delivery, traffic signal control and router
placement. Every query was therefore tied to the competition name, to exclude
unrelated work from those fields.

We also searched the names of each problem's datasets, such as `c_incunabula`
or `me_at_the_zoo`. These queries find work that reports results per dataset
without naming the problem.

The queries covered spelling variants (signaling/signalling, data
center/centre) and, for the early editions organized from Paris, French terms.

## Sources

We first queried Google Scholar, ResearchGate, arXiv, Semantic Scholar and
CORE. Only Google Scholar, which searches full texts, consistently returned
relevant results. It therefore became the only source after the first
[N] problems.

For each query, we screened [the first N results / all results].

## Screening

We screened the results manually. A work was included if it solved, analysed
or used the problem. Works that only mentioned the competition were excluded.

Some problems match the same queries, so we separated them during screening.
Examples are the 2017 Pizza and the earlier pizza problems with ham, and More
Pizza and Even More Pizza. A work covering several problems is listed under
each of them.

No relevant work was found for three practice problems: More Pizza, Even More
Pizza and One Pizza.

## Limitations

Google Scholar results change over time and are not fully reproducible, and
relying on a single source means works it does not index may be missing.
[Screening was done by one person.] If you know of a work that is not listed,
please see [CONTRIBUTING.md](CONTRIBUTING.md).
